# Đọc nhánh BE `feature/add-postgres-persistence`

> Đây là ảnh chụp nhánh BE `9b75d576`, không phải contract hiện hành. BE `c314fa8`
> `/api/health` có cờ `history` và `/api/history` trả 404 khi cờ tắt (kể cả lúc không có DB).
> Xem [BACKEND_CONTRACT.md](BACKEND_CONTRACT.md) trước khi tích hợp.

Đã đối chiếu source, tài liệu consumer contract và test tại commit [`9b75d576`](https://github.com/kiendt2312/cipher_workbench-be/tree/9b75d576f201f9df3c219fdc4f8f70834bd807ff) ngày 28/09/2026. Nội dung dưới đây mô tả **hành vi hiện có trên nhánh**, không giả định các API chưa được triển khai.

## BE đã làm gì

- PostgreSQL là **tùy chọn** qua `DATABASE_URL`. Không đặt biến này thì 15 endpoint cipher vẫn chạy, không ghi lịch sử; `GET /api/health` trả `database: "disabled"`, còn `GET /api/history` trả 503. Khi có URL, kết nối được tạo trong app lifespan và đóng lúc dừng app. App không tự tạo bảng. [config.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/config.py#L12-L16), [main.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/main.py#L28-L47), [routes_health.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/routes_health.py#L27-L42)
- Migration Alembic `0001` tạo duy nhất bảng `cipher_operations`, khóa chính identity, các check constraint và index theo thời gian / cipher. Không có bảng user, session, file hoặc nội dung cipher. [migration 0001](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/alembic/versions/0001_create_cipher_operations.py#L19-L74), [models.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/db/models.py#L38-L78)
- Mỗi `POST` tới 15 đường dẫn cipher cố định được middleware ghi **một dòng metadata sau khi response hoàn tất**, kể cả request bị từ chối. Các route khác không được ghi. Ghi thất bại hoặc quá 500 ms thì bỏ qua bản ghi, không đổi kết quả cipher; request có thể chậm thêm tối đa khoảng 500 ms vì middleware chờ ghi. [routes.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/history/routes.py#L18-L32), [history_recorder.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/history_recorder.py#L21-L85), [test_history_recording.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/tests/integration/test_history_recording.py#L89-L160)
- Một dòng gồm `id`, `createdAt`, `cipher`, `operation`, `source`, `responseMode`, `inputLength`, `outputLength`, `httpStatus`, `succeeded`, `durationMs`. **Không lưu** plaintext, ciphertext, key, tên file, nội dung file, IP, user agent hay user ID. `operation` của file và các độ dài có thể `null` khi lỗi xảy ra trước lúc parse/đo; `responseMode` luôn `null` cho text. Độ dài text là số Unicode code point, file là số byte UTF-8. [models.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/db/models.py#L38-L78), [history_recorder.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/history_recorder.py#L58-L75), [frontend-integration.md](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/repo_docs/frontend-integration.md#L1300-L1330)

## Contract FE dùng được ngay

`GET /api/health` trả `success: true`, `result.app: "ok"`, `result.database` là `ok` (200), `disabled` (200) hoặc `unavailable` (503). Trạng thái `ok` nghĩa là DB trả lời `SELECT 1` trong 1 giây. [routes_health.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/routes_health.py#L16-L42)

`GET /api/history` trả `{ "success": true, "result": { "items": [...], "nextCursor": string | null } }`. Danh sách mới nhất trước; dùng cursor do server cấp, không tự dựng. Query tùy chọn: `limit` từ 1 đến 100 (mặc định 20), `cursor`, `cipher` thuộc 5 thuật toán, `operation` là `encrypt` hoặc `decrypt`. **Chưa có filter theo `source`, trạng thái hay khoảng ngày**. Sai query trả 422 theo envelope `{success:false,message}`; DB tắt/lỗi trả 503 cùng envelope. [routes_history.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/routes_history.py#L20-L139), [store.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/history/store.py#L37-L70), [frontend-integration.md](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/repo_docs/frontend-integration.md#L1282-L1374)

API history hiện **không có xác thực và trả lịch sử chung của toàn instance**. Không có endpoint detail, delete, hoặc tải lại input/output/file. [frontend-integration.md](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/repo_docs/frontend-integration.md#L1375-L1380), [routes_history.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/routes_history.py#L99-L139)

## Hệ quả cho scope FE

1. MVP phù hợp với nhánh này là **trang nhật ký thao tác**: danh sách metadata, lọc thuật toán/chế độ, phân trang, trạng thái tải/rỗng/lỗi, và thông báo rõ khi DB `disabled` hoặc `unavailable`. Không thể làm xem nội dung lịch sử, chạy lại từ bản ghi, xóa bản ghi hoặc lịch sử riêng theo người dùng bằng contract hiện tại.
2. Không cần FE gọi API ghi lịch sử: BE tự ghi ở middleware. Mỗi lần FE gửi thêm một request cipher đều tạo thêm một dòng. Flow hiện tại preview rồi gọi lại `/file` với `response_mode=file` để tải xuống sẽ có **hai bản ghi**. FE phải giữ hai request này theo contract file hiện hành; không tự biến preview thành attachment. [history_recorder.py](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/app/api/history_recorder.py#L40-L75), [frontend-integration.md](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/repo_docs/frontend-integration.md#L1298-L1307)
3. Nếu sản phẩm muốn gọi đây là **lịch sử cá nhân** hoặc cho phép mở lại bản mã, cần BE bổ sung chủ sở hữu bản ghi, chính sách truy cập và schema/API lưu dữ liệu tương ứng. Đây là thay đổi BE/contract trước khi FE xây UI đó.
4. FE nên giữ URL `/api` tương đối và proxy tới BE trong môi trường dev; BE không bật CORS. `docker-compose.yml` của BE chạy `db` → `migrate` → `app`, app host mặc định cổng 8080; `db` chỉ publish localhost cổng 5433. [frontend-integration.md](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/repo_docs/frontend-integration.md#L1380-L1386), [docker-compose.yml](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/docker-compose.yml#L1-L38), [.env.example](https://github.com/kiendt2312/cipher_workbench-be/blob/9b75d576/.env.example#L1-L10)
